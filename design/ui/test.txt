Вам необходимо спроектировать тест кейсы для UI из итерации 2:

Итерация 2:
1. Депозит денег пользователем
2. Перевод денег с одного аккаунта на другой
3. Изменение имени пользователя

Требования:
1) Имя профиля - два слова состоящие только из букв обязательно
2) Максимальная сумма депозита 5000
3) Максимальная сумма перевода 10000


1. Депозит денег пользователем------------------------------------------------------------------------------------------
Позитивный кейс:
1)Пользователь может сделать депозит
Предусловие:
    админ залогинелся, админ создал пользователя, пользователь залогинелся, пользователь создал аккаунт.
Шаги:
    1. Пользователь нажал Deposit Money
    2. Выбрать свой аккаунт в поле Select Account
    3. Заполнить поле Enter Amount значением от 0.1 до 5000
    4. Нажать кнопку Deposit
    5. Запросить через API аккаунт на который был выполнен депозит и проверить баланс
Ожидаемый результат:
    1. Произошел переход на страницу Deposit Money
    2. Поле Select Account заполнено
    3. Поле Enter Amount заполнено
    4. Появился алерт об успешно депозите.
    5. Аккаунт получен по API и баланс соответствует ожидаемому значению

Негативный кейс:
1)Сообщение об ошибке при депозите выше лимита
Предусловие:
    админ залогинелся, админ создал пользователя, пользователь залогинелся, пользователь создал аккаунт.
Шаги:
    1. Пользователь нажал Deposit Money
    2. Выбрать свой аккаунт в поле Select Account
    3. Заполнить поле Enter Amount значением от 5005
    4. Нажать кнопку Deposit
    5. Запросить через API аккаунт на который был выполнен депозит и проверить баланс
Ожидаемый результат:
    1. Произошел переход на страницу Deposit Money
    2. Поле Select Account заполнено
    3. Поле Enter Amount заполнено
    4. Появился алерт с сообщением об ошибке.
    5. Аккаунт получен по API и баланс соответствует ожидаемому значению (ноль)

2. Перевод денег с одного аккаунта на другой----------------------------------------------------------------------------
Позитивный кейс:
1)Перевод денег от одного пользователя другому
Предусловие:
    админ залогинелся, админ создал двух пользователей, пользователь А залогинелся, пользователь А создал аккаунт и депозит
     на свой счет, пользователь B залогинелся, пользователь B создал аккаунт.
Шаги:
    1. Пользователь А нажал Make a Transfer
    2. Выбрать свой аккаунт в поле Select Your Account
    3. Заполнить поле Recipient Name пользователем B
    4. Заполнить поле Recipient Account Number пользователя B
    5. Ввести сумму перевода в поле Amount
    6. Нажать кнопку Send Transfer
    7. Запросить через API аккаунт пользователя А
    8. Запросить через API баланс аккаунта пользователя B
Ожидаемый результат:
    1. Произошел переход на страницу Make a Transfer
    2. Поле Select Your Account заполнено
    3. Поле Recipient Name заполнено
    4. Поле Recipient Account Number заполнено
    5. Поле Amount заполнено
    6. Появился алерт об успешном переводе.
    7. Аккаунт пользователя А получен по API и баланс соответствует ожидаемому значению
    8. Аккаунт пользователя B получен по API и баланс соответствует ожидаемому значению

Негативный кейс:
1)Ошибка перевода денег с превышением лимита
Предусловие:
    админ залогинелся, админ создал двух пользователей, пользователь А залогинелся, пользователь А создал аккаунт и депозит
     на свой счет, пользователь B залогинелся, пользователь B создал аккаунт.
Шаги:
    1. Пользователь А нажал Make a Transfer
    2. Выбрать свой аккаунт в поле Select Your Account
    3. Заполнить поле Recipient Name пользователем B
    4. Заполнить поле Recipient Account Number пользователя B
    5. Ввести сумму перевода 10100 в поле Amount
    6. Нажать кнопку Send Transfer
    7. Запросить через API аккаунт пользователя А
    8. Запросить через API баланс аккаунта пользователя B
Ожидаемый результат:
    1. Произошел переход на страницу Make a Transfer
    2. Поле Select Your Account заполнено
    3. Поле Recipient Name заполнено
    4. Поле Recipient Account Number заполнено
    5. Поле Amount заполнено
    6. Появился алерт с сообщением об ошибке.
    7. Аккаунт пользователя А получен по API и баланс соответствует ожидаемому значению
    8. Аккаунт пользователя B получен по API и баланс соответствует ожидаемому значению


3. Изменение имени пользователя-----------------------------------------------------------------------------------------
    Позитивный кейс:
    1)Пользователь может изменить имя
    Предусловие:
        админ залогинелся, админ создал пользователя, пользователь залогинился
    Шаги:
        1. Нажать на профиль
        2. Заполнить имя профиля
        3. Нажать на Save Changes
        4. Запросить через API данные профиля пользователя
    Ожидаемый результат:
        1. Произошел переход на страницу Edit Profile
        2. Поле с именем заполнено
        3. Появился алерт об успешном изменении имени.
        4. Аккаунт пользователя получен по API и имя соответствует ожидаемому значению

    Негативный кейс:
    1)Ошибка при сохранении некорректного имени
    Предусловие:
        админ залогинелся, админ создал пользователя, пользователь залогинился
    Шаги:
        1. Нажать на профиль
        2. Заполнить имя профиля одним словом
        3. Нажать на Save Changes
        4. Запросить через API данные профиля пользователя
    Ожидаемый результат:
        1. Произошел переход на страницу Edit Profile
        2. Поле с именем заполнено
        3. Появился алерт с сообщением об ошибке.
        4. Аккаунт пользователя получен по API и имя соответствует ожидаемому значению
